# 三国人物测试

一个纯静态、手机端优先的双语历史人格测试页。页面从 `sanguo-quiz-cn.json` 和 `sanguo-quiz-en.json` 读取题目、结果和所有界面文案，不需要后端或业务 API。

## 文件

- `index.html`：页面骨架
- `app.js`：题目状态、计分、结果卡片、像素头像和分享逻辑
- `style.css`：移动端优先样式与结果卡片布局
- `sanguo-quiz-cn.json`：中文配置（默认）
- `sanguo-quiz-en.json`：英文配置

## 本地预览

1. 在此目录启动静态服务器，例如 `python -m http.server 8000`。
2. 浏览器打开 `http://localhost:8000/`；英文版打开 `http://localhost:8000/?lang=en`。
3. 修改文件后刷新页面。也可以直接双击 `index.html`，但部分浏览器会限制 `fetch` 读取 JSON，静态服务器更可靠。

## GitHub Pages 部署

1. 将本目录中的 `index.html`、`app.js`、`style.css` 与两份 JSON 提交到仓库根目录。
2. 在 GitHub 仓库进入 **Settings → Pages**，选择部署分支和 `/ (root)`。
3. 保存后等待 GitHub Pages 构建，使用生成的地址访问；查询参数 `?lang=en` 和 `?r=OSK` 可直接分享。

## 计分与测试矩阵

每个维度有 4 题，每题选项向一个极加 2 分；同分时取配置中该维度的 `left` 极。按当前 JSON 的代码映射：行动为 `O/S`，谋略为 `S/O`，守成为 `K/R`。下面的“每组四题”指该维度的 4 道题都选对应一侧的任意选项；不同题目的选项顺序不同，请按选项的实际极性构造答案。

| 计分极（行动 / 谋略 / 守成） | 结果代码 | 当前配置结果 | 可否测出 |
| --- | --- | --- | --- |
| 左 / 左 / 左 | `OSK` | 诸葛亮 | 可以 |
| 左 / 左 / 右 | `OSR` | 关羽 | 可以 |
| 左 / 右 / 左 | `OOK` | 曹操 | 可以 |
| 左 / 右 / 右 | `OOR` | 吕布 | 可以 |
| 右 / 左 / 左 | `SOK` | 赵云 | 可以 |
| 右 / 左 / 右 | `SOR` | 周瑜 | 可以 |
| 右 / 右 / 左 | `SSK` | 刘备 | 可以 |
| 右 / 右 / 右 | `SSR` | 司马懿 | 可以 |

中文与英文配置均已统一为上述 8 个唯一结果 code，好友链接会校验三位大写 code，非法 code 会被忽略。平分时使用对应维度的 left 极（中文为动/谋/守）。

- [x] **手机端布局**：主容器最大宽度 480px；按钮最小高度 44px；结果核心区采用头像、姓名、判语、标签的截图友好层级。
- [x] **品牌视觉**：样式变量使用配置品牌色 `#F25C3B`，像素头像画布固定 120px 并启用 `image-rendering: pixelated`。

- [x] **分享**：普通浏览器使用 Clipboard API；不可用时显示可长按选中的文案区域，并保留复制链接和复制结果两个入口。
